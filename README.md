I build real-time 3D for mobility and robotics: low-poly assets in **Blender**, simulation
environments and logic in **Unreal Engine 5**, and the small local tools that keep the
asset pipeline honest. When a workflow gets repetitive, I write something to do it for me.

### What I actually work on

**Simulation environments** — building scenes and behaviour in Unreal Engine 5 with Blueprint
and C++, aimed at logistics and mobility use cases rather than games.

**The Blender → Unreal pipeline** — modelling optimized low-poly assets, keeping triangle
budgets, pivots and scale correct so nothing breaks on import.

**Pipeline tooling** — Python, Node and Three.js utilities for inspecting and optimizing
`.glb` models: polygon counts, texture sizes, mesh simplification, before/after comparison.

**AI-assisted development** — Claude Code, Blender MCP and generative tooling as part of the
day-to-day loop, not as a novelty.
